## Catatan & celah v1 (jujur)
- API itu elemen paling tipis: hanya ±3 menit total dari 3 berkas pendek.
  Untuk bed api unggun/perapian 1 jam, loop seamless tool kita bisa
  memakainya, tapi variasi kreseknya terbatas. Sumber api panjang yang
  bagus umumnya di Freesound (perlu login akun — Kevin pernah memakai
  Freesound untuk hujan 13:52 WAV 24-bit). Usulan: sesi unduh Freesound
  berlisensi CC0/CC BY memakai akun Kevin, khusus elemen api + hujan
  deras panjang.
- Kandidat hujan sangat panjang di Commons: "Calm rain.wav" (CC BY-SA
  4.0, 330 MB) belum diunduh — bisa diambil bila bed hujan >4 menit
  dirasa kurang.
- Belum ada: jangkrik malam panjang, hujan di atap/tenda, sungai besar
  panjang, ombak panjang. Masuk daftar buru v2 bersama Freesound.
- Berkas mono jangan dijadikan satu-satunya bed; pakai sebagai layer
  tengah di bawah bed stereo.
- Pustaka ini tinggal di ~/workspace/asmr-service/library/ (di luar repo
  git asmr-tools agar repo bersih); tool membaca berkas dari path ini
  lewat panel unggah/berkas.
