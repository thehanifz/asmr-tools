# Privacy Policy — Youtube-muse-L (asmr-tools YouTube uploader)

Effective date: 16 November 2026

## What this app is

Youtube-muse-L is a private, single-user tool used by the owner of the
**Xtra Dimention** YouTube channel to upload the channel's own videos
through the YouTube Data API v3. It is part of the asmr-tools project and
is not offered to the public.

## What data the app accesses

With the channel owner's consent, the app uses these Google API scopes:

- `https://www.googleapis.com/auth/youtube.upload` — upload video files
  to the owner's own channel.
- `https://www.googleapis.com/auth/youtube` — set thumbnails, manage
  video metadata and playlists on the owner's own channel.

The app does not read, collect, or store any other Google account data.

## How data is stored and used

- OAuth access and refresh tokens are stored locally on the owner's
  private server, in a permission-restricted folder, and are used only
  to perform the uploads described above.
- No personal data is sold, shared, rented, or transferred to any third
  party. No analytics or advertising trackers are involved.
- Video files and metadata are sent only to YouTube's own API endpoints.

## Revoking access

The owner can revoke this app's access at any time via
Google Account → Security → Third-party access
(https://myaccount.google.com/permissions), and by deleting the locally
stored token file.
