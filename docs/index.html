Youtube-muse-L

Youtube-muse-L is a private, single-user tool used by the owner of the Extra Dimension YouTube channel (formerly “Xtra Dimention”) to upload the channel's own videos through the YouTube Data API v3. It is part of the open-source asmr-tools project and is not offered to the public.

With the channel owner's consent, the app uses the YouTube API to upload video files, set thumbnails, and manage video metadata and playlists on the owner's own channel only. It does not read, collect, or store any other Google account data, and no data is sold, shared, or transferred to any third party.
